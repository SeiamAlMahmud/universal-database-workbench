Electron Install Issue (Forge Start) - Quick Fix
=================================================

Issue Symptoms
--------------
`pnpm run start` দিলে নিচের error আসতে পারে:

Error: Electron failed to install correctly, please delete node_modules/electron and try installing again

Common Root Cause
-----------------
- `node_modules/electron/path.txt` missing থাকে
- অথবা `node_modules/electron/dist/electron.exe` missing/corrupt থাকে
- Electron postinstall script ঠিকমতো run হয়নি

Fast Recovery Steps (Windows, PowerShell)
-----------------------------------------
1) Project folder এ যাও:
   cd D:\Personal\universal-database-workbench

2) Electron installer script manually run করো:
   node node_modules\electron\install.js

3) Verify path file আছে:
   Get-Content node_modules\electron\path.txt
   Expected output: electron.exe

4) Verify binary আছে:
   Test-Path node_modules\electron\dist\electron.exe
   Expected output: True

5) App start করো:
   pnpm run start

If It Still Fails
-----------------
1) Electron package clean reinstall:
   Remove-Item -Recurse -Force node_modules\electron
   pnpm add -D electron@^31.0.1
   node node_modules\electron\install.js
   pnpm run start

2) Full reinstall (last resort):
   Remove-Item -Recurse -Force node_modules
   Remove-Item -Force pnpm-lock.yaml
   pnpm install
   pnpm run start

Important Note
--------------
- কিছু environment-এ Electron cache path (`%LOCALAPPDATA%\electron\Cache`) এ write permission দরকার হয়।
- যদি permission/sandbox issue দেখায় (`EPERM`), command elevated terminal থেকে run করো।

Extra Warning (Non-blocking)
----------------------------
- `MODULE_TYPELESS_PACKAGE_JSON` warning (postcss.config.js) crash cause না।
- এটা performance warning; app usually ঠিকমতো run করে।
