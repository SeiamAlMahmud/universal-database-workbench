Electron Blank Screen + Install Runtime Fix (Windows)
=====================================================

Date: 2026-03-08
Project: murgiDB

Symptoms
--------
1) App opens but window stays blank (dark/black screen).
2) Terminal shows cache errors like:
   - Unable to move the cache: Access is denied (0x5)
   - Unable to create cache
   - Gpu Cache Creation failed: -2

Root Causes
-----------
1) Packaged renderer HTML path mismatch (main process tried wrong index.html path).
2) Chromium cache directory permission issue in some Windows installs.
3) No visible startup error dialog, so user only sees blank window.

Code Fixes Applied
------------------
File: src/main/index.ts

1) Renderer load path fix (for Electron Forge + Vite)
   - Use: .vite/renderer/<windowName>/index.html
   - Keep fallbacks for legacy paths.

2) Force writable runtime data paths
   - userData   -> %APPDATA%\\murgiDB
   - sessionData -> %APPDATA%\\murgiDB\\SessionData
   - disk-cache-dir -> %APPDATA%\\murgiDB\\SessionData\\Cache

3) Error visibility (no silent blank screen)
   - Show dialog if loadURL/loadFile fails.
   - Show dialog on did-fail-load.
   - Show dialog if renderer process crashes (render-process-gone).

How To Rebuild and Install
--------------------------
1) Close the app completely.
2) Remove old data folders if they exist:
   - %APPDATA%\\murgiDB
   - %LOCALAPPDATA%\\murgiDB
   - %APPDATA%\\DB Workbench (old app name, if exists)
3) Build installer again:
   pnpm run make
4) Install the new installer from out\\make\\...

If Electron Binary Is Broken (dev environment)
----------------------------------------------
If `pnpm run start` says Electron failed to install:

1) Run:
   node node_modules\\electron\\install.js
2) Verify:
   Get-Content node_modules\\electron\\path.txt
   Test-Path node_modules\\electron\\dist\\electron.exe
3) Retry:
   pnpm run start

Last Resort
-----------
1) Remove node_modules and lock file:
   Remove-Item -Recurse -Force node_modules
   Remove-Item -Force pnpm-lock.yaml
2) Reinstall and rebuild:
   pnpm install
   pnpm run make

Notes
-----
- DevTools warnings like `Autofill.enable wasn't found` are not the main crash reason.
- Primary blocker was renderer path + Windows cache permission.
